# Alpha to Zendikar

A small interactive **Magic: The Gathering alphabet book** built as a single-page web experience.

Each page pairs a letter with a Magic reference, presenting the project like a digital picture book rather than a conventional card database or deckbuilding tool.

## About

The project is intentionally lightweight: the entire experience lives in `index.html`, with the layout, styling, navigation, and content kept together so it can be hosted as a static site with no build step.

## Run locally

No dependencies are required. Open `index.html` directly in a browser, or serve the directory with any static web server.

For example:

```sh
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Implementation

- Semantic HTML
- Responsive CSS
- Vanilla JavaScript
- Static hosting friendly
